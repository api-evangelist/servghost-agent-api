## For AI Agents — Buy a Server Programmatically

ServGhost is fully agent-purchasable. AI agents (Claude, Claude Code, ChatGPT, Cursor, Continue, OpenClaw, custom Python scripts, etc.) can discover, price, top up balance, deploy servers and receive credentials end-to-end with zero human interaction.

**Payment model is BALANCE-ONLY.** No direct crypto-to-server purchases. Two-step flow:
  1. Top up USD credit with crypto via `POST /api/v1/topup` (min $30, max $2000 per top-up, with automatic bonus credit — see below).
  2. Deploy servers from the credit via `POST /api/v1/orders` (debits balance, server is active immediately).

If `/api/v1/orders` is called with insufficient balance it returns `402 insufficient_balance` with a `topup_required` block including a `suggested_usd` value that covers the deficit AND clears the $30 minimum — pass it straight back to `/api/v1/topup` and retry.

**Top-up bonus tiers** (free credit applied on confirmation, linear interpolation between anchors, no bonus below $100):
  $100 → +$25     |    $1000 → +$500
  $250 → +$75     |    $1500 → +$1000
  $500 → +$200    |    $2000 → +$2000
Full tier table: `GET https://servghost.com/api/v1/topup/bonus` (no auth).

Two integration paths, all on the same domain (no subdomain):

1. **MCP** (Claude Desktop / Code, Cursor, Continue, Cline) — add this URL to your MCP config:
   `https://servghost.com/mcp`
   Tools exposed: `list_plans`, `list_locations`, `quote`, `topup_bonus`, `topup_create`, `payment_status`, `account_balance`, `create_order`, `server_credentials`, `server_action`, `agent_help`.

2. **REST** — OpenAPI 3.1 spec at `https://servghost.com/openapi.json`. Bearer auth (auto-issued on first `/topup` or `/orders` POST, no signup needed).
   - `GET  /api/v1/topup/bonus`              — bonus tier table
   - `POST /api/v1/topup    {amount, crypto}` — create deposit invoice
   - `GET  /api/v1/topup/{id}`               — poll until status=confirmed
   - `POST /api/v1/orders   {type, plan, location, os, billing}` — balance-debit deploy
   - `GET  /api/v1/servers/{id}`             — credentials (active immediately)

Discovery file (machine-readable capabilities): `https://servghost.com/.well-known/agent.json`
Agent docs (humans + scrapers): `https://servghost.com/agents`
Test mode (no real crypto, no real provisioning): add `?dry_run=1` to any `/api/v1/*` URL or pass `dry_run: true` in the body.
